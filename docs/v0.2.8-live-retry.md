# v0.2.8 live retry

The previous source-only v0.2.7 release had not been loaded by the installed daemon. The live Codex renderer still reported controller 0.2.6, so the Plugins header remained pale. A backup of the installed `main.mjs` was kept locally, the current source was bundled to a temporary JS file, and that JS file replaced only GPTDaddy's installed `main.mjs`. The exact installed daemon was restarted without closing Codex.

Afterward, the official Codex page reported controller 0.2.7 and the Plugins shell had `data-gptdaddy-flat-header`; its computed `::before` background was transparent. A real screenshot showed the white bar gone. The source was then updated to v0.2.8 to recognize plain floating text-selection toolbars and loaded the same way. The live Plugins header remained transparent with controller 0.2.8. No Setup.exe or portable package was made for this retry.

The text-selection toolbar and View changes button were absent from the inspected live page. Their post-change appearance remains unverified. All 34 automated tests passed.
